# ece402

Personal coursework archive for a college electrical circuits course, kept by Abdon Morales.

Note on the repo name: this repository is named `ece402` as a personal shorthand from when the coursework began. The actual course is **ACC ENGR 2405**, described below.

## Academic Integrity

The homework solutions and lab reports in this repository are the owner's own coursework, shared here for personal reference and portfolio purposes. They are not intended to be copied or submitted by other students, and doing so would violate academic integrity policies at ACC or any other institution.

## Course Information

| | |
|---|---|
| Course | ENGR 2405 – Electrical Circuits I |
| Institution | Austin Community College (ACC) |
| Term | Summer 2026 (SU26), Section 001 |
| Instructor | Purna Murthy |
| Credit hours | 4 (3 lecture + 3 lab contact hrs/week) |
| Textbook | Alexander & Sadiku, *Fundamentals of Electric Circuits*, 7th edition |
| Software | SciLab, LTspice |
| Prerequisites | Calculus II, Engineering Physics II |

Topics covered: circuit elements, Kirchhoff's laws, node and mesh analysis, op-amps, Thévenin/Norton equivalents, transient response, sinusoids and phasors, AC steady-state analysis, AC power, three-phase circuits, frequency response and Bode plots, circuit simulation (SciLab/LTspice), lab instrumentation, and lab report writing.
